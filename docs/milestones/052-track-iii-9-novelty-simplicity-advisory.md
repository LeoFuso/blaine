## Hypothesis and execution boundary

Can fresh, scoped workspace advice reduce duplicate abstraction choices while
preserving legitimate additions and material near-match distinctions? The
[experiment](../../experiments/track-iii-009/README.md) separates novelty (contract
compatibility with an existing target) from simplicity (whether another abstraction
or wrapper is justified). Generic guidance is identical in both conditions; the
variable is the workspace packet. Neither similarity nor advice blocks an action.

The UI interruption left only valid source/proposal fixtures, with no inference or
discovery evidence. [Recovery](../../experiments/track-iii-009/evidence/recovery.json)
verified every file and both revision manifests, preserved them and resumed at the
first incomplete step. No completed model call or fixture generation was repeated.

Exactly 12 proposals were frozen: four duplicates, four legitimate additions, four
near-match contract mismatches. Proposal manifest SHA-256:
`54c7e368549820df132102a3682342eed01e9d193d5fdac7e87888ae1297b2f5`.
The two 18-file synthetic Python snapshots include neighboring concepts, interfaces,
imports/calls, cloned telemetry and a protected namespace. Current cognition uses B;
A's renamed/moved fold declaration supplies a stale-index control. Oracles, contracts,
queries, security, guidance and thresholds were frozen before model comparison.

Duplicates cover casefolding, retry policy, acknowledgement memoization and atomic
file overwrite. Legitimate additions require different lifecycle, quota ownership,
immutable versions or comparison responsibilities. Near-matches materially differ in
case preservation, 429-versus-5xx admission, durable-versus-RAM storage or append-versus-
overwrite semantics. No obscure incidental difference determines the expected choice.

## Decision, limitations and next proposal

Scoped workspace advisory demonstrates finite behavioral value; **a hard gate is not
justified**. This evaluates decisions about synthetic code, not implemented changes,
long-term entropy or arbitrary semantic equivalence. The baseline lacks the broad
packet but retains its natural local evidence; unrestricted exploration is not tested.
The simplicity wording and structural evidence have no separate causal ablation.
Some contract detail is absent from 80-character excerpts (for example, the exact
Ledger hash algorithm); correct target choice does not prove all details were checked.

No production Cognitive Loop, routing, Memory, promotion, verified-outcome admission,
Restate or remote-execution behavior changed. The retained TaskSpec is unsubmitted.
Costs include embedding/extraction, source validation, extra context and format
recovery. Unresolved: richer contract representation, partial evidence/uncertainty,
action-time source validation, larger repositories, incremental freshness, human
review and downstream coding outcomes. No primary failure taxonomy applies; the
isolated mutation demonstrates representation corruption causing false equivalence.

[Exact III.10 proposal](../../experiments/track-iii-009/README.md#exact-proposed-iii10-experiment--not-started):
12 trusted-lineage transfer cases across local handoffs, checkpoint/resume and a
second process. Test valid transitions, forged scope/provenance, changed policy,
malformed topology and replay with missing outcome evidence. Require exact read/write/
provenance outcomes, zero scope expansion or forbidden metadata, 2 KiB responses and
current-authority revalidation; catch serialized-scope and stale-policy mutations.
Use isolated synthetic bindings, not production lifecycle/authentication integration.
**III.10 has not started.** No human architectural decision is required to close
III.9; the next experiment requires explicit authorization.
